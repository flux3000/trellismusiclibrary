**Fresh installs only.** This release renames tables in the library database, and there is no upgrade path from 0.2.1 yet. If you have an earlier version installed, remove its database before opening this one. An upgrade path is coming.

**Artists and Musicians.** The act on the poster is now an Artist. The people in it are Musicians. "Performer" is retired. Labels, pages and links throughout the app follow the new names.

**Standard FLAC tags.** Trellis writes a consistent tag set on ingest. ARTIST and ALBUMARTIST carry the act, ALBUM is the date and venue, PERFORMER lists each musician in the show's resolved lineup, and VENUE, LOCATION and SOURCE replace the older CONCERT* fields. A track's note is written to COMMENT.

**Bring your own library.** First run has a second answer: point Trellis at a collection you already have, instead of having it build a new folder tree. Download, Backlog and Workshop are optional, and Trellis will not create them for you.

**Filing layout.** New material can file under an Artist folder or sit flat at the library root. The setting is per install and governs new ingests only. Nothing already in the library moves.

**Metadata from tags.** A folder with no info file is no longer a dead end. Trellis reads date, venue and source from the FLAC tags, which is the usual case for a collection that was tagged before it got here.

**AI Assist.** You can ask a question before a run, so the research answers what you want to know. Lineup research has its own button, and its results are saved with the artist instead of disappearing when you navigate away. Usage is reported as tokens and web searches, with no dollar figures anywhere.

**License.** The MIT license has been withdrawn. The source stays published so anyone can read what the app does with their files and their network connection. Terms are under review.
