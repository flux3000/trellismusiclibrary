Info file — mono or primary face

A real info file out of the library (Brian Wilson, BBC Radio 2, 1998). Press M to swap it between JetBrains Mono and the primary face. Worth deciding with your eyes open: this is the taper's own text, and collectors hand-align these — the track/time columns below are tab-aligned, and a proportional face re-flows them. Mono preserves whatever the author built; the primary face reads better as prose. Everything else is now off mono — the FFP column in the track list and the lineage block both moved to the primary face, and the lineage rebuilt as a real two-column grid rather than labels padded out with spaces, which only ever aligned because it was monospaced.

Left nav and Recording header

Rebuilt. It had five type treatments — 8, 10, 11, 12 and 12px across three weights and three colours — which is why it read as five different fonts when it was only ever one. Now there are two: an uppercase section header at 11px, and a single 12px item size shared by Browse, the Collections rows, the favourites and the dimension links — so Collections is no longer the 10px runt. Depth is carried by indentation and colour, never by shrinking text. The sidebar is 300px wide, up from 264, so show titles get further before they truncate.
